# Sistema de Registro de Estudiantes
## Descripción
Este proyecto es un sistema interactivo en consola desarrollado en C++ para la gestión y validación de estudiantes dentro de un módulo de matriculación académica.
## Objetivo
Proporcionar una solución automatizada para el registro de alumnos, asegurando el formato y la validación correcta de los documentos de identidad.
## Funcionalidades
- Menú principal interactivo de opciones.
- Módulo para el ingreso de datos del estudiante.
- Módulo de validación de cédula a 10 dígitos.
- Interfaz y mensajes de confirmación en consola.
## Tecnologías utilizadas
- Lenguaje: C++
- Compilador / Entorno: GCC / VS Code
- Control de versiones: Git
- Plataforma remota: GitHub
## Estructura del proyecto
- `main.cpp`: Código fuente principal del sistema con la lógica y menús.
- `.gitignore`: Archivo de configuración para omitir archivos temporales y compilados.
- `README.md`: Documentación oficial del proyecto.
## Instalación o ejecución
1. Clonar el repositorio:
`git clone https://github.com/DanielY94/registro-estudiantes.git`
2. Abrir la carpeta del proyecto en la terminal.
3. Compilar el archivo principal:
`g++ main.cpp -o registro-estudiantes`
4. Ejecutar el programa:
`./registro-estudiantes`
